# Building Decentralized Identity (DIDs) with Midnight

This submission fulfills bounty issue [#228](https://github.com/midnightntwrk/contributor-hub/issues/228): **[Tutorial] Building Decentralized Identity (DIDs) with Midnight**.

## Deliverables

- **Published tutorial:** [Building Privacy-Preserving Identity Systems with DIDs on Midnight](https://dev.to/peter_maina_86d76a47575ea/building-privacy-preserving-identity-systems-with-dids-on-midnight-22gg)
- **Working code repository:** [kanyuku/my-did-tutorial](https://github.com/kanyuku/my-did-tutorial)
- **Social post:** [LinkedIn announcement](https://www.linkedin.com/posts/peter-kanyuku-7a909b264_github-kanyukumy-did-tutorial-activity-7451942820644352001-5sy4)

## Coverage

The tutorial and companion repository demonstrate an end-to-end privacy-preserving decentralized identity flow on Midnight, including:

- DID concepts and the issuer-holder-verifier model
- Verifiable credential issuance and verification
- Privacy-preserving credential checks without exposing underlying personal data
- Practical examples for identity verification use cases
- Local setup and testing instructions in the companion repository

## Primary Use Cases

- Age or eligibility verification without revealing unnecessary personal information
- KYC-style credential verification using privacy-preserving disclosure patterns
