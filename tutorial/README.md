# Tutorial: Working with Maps and Merkle Trees in Compact

This repository contains two working examples:
- Map-based registry (MapRegistry.compact)
- Merkle-tree-based allowlist (MerkleAllowlist.compact)

## Map Registry
Demonstrates insert, lookup, delete, and iteration.

## Merkle Allowlist
Demonstrates add, verify, and remove with depth-20 path verification.

## Requirements
- Midnight MCP
- Node.js

## Usage
Follow the tutorial on Dev.to for detailed instructions.
