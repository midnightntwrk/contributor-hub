# Shielded Token Operations: Mint, Transfer & Burn with Test Suite

## Introduction

This tutorial walks through the complete lifecycle of shielded tokens in Compact, covering minting, transferring, and burning operations. We'll implement a Compact contract, TypeScript witnesses, and a comprehensive test suite using vitest.

## Prerequisites

- Basic understanding of Midnight's Compact language
- Familiarity with TypeScript
- Node.js and npm installed
- Midnight development environment set up
